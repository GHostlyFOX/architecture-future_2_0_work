# Task 3 Advanced: Проектирование целевой архитектуры Future 2.0

В данной директории содержатся артефакты проектирования целевой архитектуры компании "Будущее 2.0" (горизонт 3 года) и анализ рисков.

## Структура

*   `c4_containers.puml`: C4-диаграмма уровня контейнеров (PlantUML), описывающая общую архитектуру платформы, взаимодействие доменов (Медицина, Финтех, ИИ) через шину событий, и интеграцию с платформой данных.
*   `c4_components_data_platform.puml`: C4-диаграмма уровня компонентов (PlantUML) для подсистемы "Data & Analytics Platform" (включая Портал самообслуживания). Детализирует потоки данных от Kafka до витрин (Data Marts) и UI.
*   `risks.md`: Карта рисков трансформации (Архитектурные, Организационные, Технологические) и План управления ими.

## Как просмотреть диаграммы

Диаграммы описаны на языке PlantUML. Для просмотра можно использовать:
1.  Онлайн-редактор [PlantText](https://www.planttext.com/) или официальный [PlantUML Server](http://www.plantuml.com/plantuml/). Просто скопируйте содержимое `.puml` файлов в редактор.
2.  Плагины для IDE (VS Code, IntelliJ IDEA).
3.  Утилиту командной строки `java -jar plantuml.jar`.

## Ключевые архитектурные решения

*   **Event-Driven Architecture (EDA):** Основной паттерн взаимодействия — асинхронный обмен событиями через Event Bus (Kafka/Pulsar). Это обеспечивает слабую связность и масштабируемость.
*   **Microservices / Domain-Driven Design (DDD):** Четкое разделение на домены (Медицина, Финтех, ИИ), каждый со своим стеком и БД.
*   **Data Mesh / Lakehouse:** Платформа данных объединяет свойства Data Lake (хранение сырых данных) и Data Warehouse (аналитика). Реализован принцип самообслуживания через Data Portal.
*   **Отказ от легаси:** Монолитный DWH и ESB (Camel) заменяются на современные потоковые решения (Streaming ETL) и API Gateway.
