# Технологический Радар (Future 2.0)

В данном документе представлен целевой технологический стек и архитектурные паттерны компании "Будущее 2.0" на горизонте трех лет.

Статусы:
*   **Adopt:** Основная технология, используемая в продакшене. Рекомендована для новых проектов.
*   **Trial:** Технология используется в пилотных проектах. Риск управляемый.
*   **Assess:** Технология исследуется, проводятся PoC (Proof of Concept).
*   **Hold:** Технология устарела или не рекомендована. Поддержка только существующих систем.

## 1. Архитектура и Паттерны (Architecture & Patterns)

| Технология / Паттерн | Статус | Описание |
|---|---|---|
| **Microservices** | Adopt | Разделение монолита на независимые сервисы по доменам. |
| **Event-Driven Architecture (EDA)** | Adopt | Асинхронное взаимодействие через шину событий (Kafka). |
| **Data Mesh** | Trial | Децентрализованное управление данными. Владение данными на уровне доменов. |
| **Domain-Driven Design (DDD)** | Adopt | Моделирование сложной бизнес-логики через Bounded Contexts. |
| **CQRS** | Assess | Разделение операций чтения и записи для высоконагруженных сервисов. |
| **Monolithic DWH** | **Hold** | Централизованное хранилище данных (SQL Server). Постепенный отказ. |
| **SOA (Service Oriented Arch)** | **Hold** | Использование тяжелой шины ESB (Camel) для интеграций. |

| **Terraform (IaC)** | Adopt | Управление инфраструктурой как кодом. |
| **Yandex Cloud / AWS** | Adopt | Облачная инфраструктура (IaaS/PaaS). |
| **GitLab CI/CD** | Adopt | Автоматизация сборки и развертывания. |

| **Prometheus / Grafana** | Adopt | Мониторинг и визуализация метрик. |
| **ELK / OpenSearch** | Adopt | Агрегация логов. |
| **On-premise Servers** | **Hold** | Физические сервера в собственных ЦОД. Миграция в облако. |

## 3. Данные и Аналитика (Data & Analytics)

| Технология | Статус | Описание |
|---|---|---|
| **Apache Kafka** | Adopt | Шина событий и потоковая передача данных. |
| **S3 (Object Storage)** | Adopt | Озеро данных (Data Lake) для хранения сырых событий и файлов. |
| **ClickHouse** | Trial | Аналитическая OLAP база данных для быстрых отчетов. |
| **PostgreSQL** | Adopt | Основная реляционная БД для микросервисов. |
| **Apache Flink / Spark** | Assess | Потоковая обработка данных (Stream Processing). |
| **dbt (Data Build Tool)** | Trial | Трансформация данных в DWH/Lakehouse (ELT). |
| **Superset / Metabase** | Trial | BI-инструменты с поддержкой Self-Service. |
| **MS SQL Server 2008** | **Hold** | Устаревшее DWH. Поддержка до окончания миграции. |
